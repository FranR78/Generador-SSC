## Objeto y alcance

Explicar las características y configuración general del circuito frigorífico en los sistemas de climatización de tres y cuatro zonas.

## Fundamento

El circuito utiliza fluido refrigerante R134a y cuenta con un único evaporador para dar cobertura a las diferentes zonas. Además, incorpora un intercambiador térmico interno para optimizar el consumo de combustible y reducir las emisiones de CO2.

## Desarrollo

- El sistema de climatización de tres y cuatro zonas funciona con el refrigerante R134a.  
- El circuito integra un solo evaporador para todo el sistema de climatización.  
- Incorpora un intercambiador térmico interno para maximizar el ahorro de combustible y minimizar las emisiones de CO2.

## Seguridad y normativa

Reducción de emisiones de CO2.
