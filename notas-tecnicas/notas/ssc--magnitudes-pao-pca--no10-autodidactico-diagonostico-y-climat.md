## Objeto

Cuantificar y evaluar el impacto ambiental relativo de cada gas refrigerante sobre la destrucción de la capa de ozono y sobre el calentamiento global de la atmósfera (pág. 10).

## Fundamento

Utilización de dos índices numéricos estandarizados internacionalmente: el Potencial de Agotamiento de Ozono (PAO / ODP) y el Potencial de Calentamiento Atmosférico (PCA / GWP) (pág. 10).

## Desarrollo

1. Potencial de Agotamiento de Ozono (PAO / ODP):
Mide la capacidad de una sustancia para destruir el ozono estratosférico en comparación con el refrigerante R11 o R12, al que se asigna un valor patrón de PAO = 1,0 (págs. 1, 10).
- Refrigerantes bromados: PAO = 5 a 15 (máxima destructividad por presencia de bromo) (pág. 10).
- CFC (R11, R12): PAO = 1,0 (pág. 10).
- HCFC (R22): PAO = 0,05 (bajo por contener hidrógeno, que reduce su estabilidad atmosférica) (pág. 10).
- HFC (R134a) y HFO (R1234yf): PAO = 0 (no dañan la capa de ozono al carecer de cloro o bromo) (pág. 10).

2. Potencial de Calentamiento Atmosférico (PCA / GWP):
Índice que mide la capacidad de una sustancia para retener calor por efecto invernadero en un horizonte de 100 años, tomando como valor de referencia una masa equivalente de CO2 (PCA = 1,0) (págs. 1, 10).
- CO2 (R744): PCA = 1 (pág. 10).
- R1234yf (HFO): PCA = 4 (págs. 10, 26).
- R152a (HFC): PCA = 124 (pág. 10).
- R134a (HFC): PCA = 1430 (págs. 1, 10).
- R12 (CFC): PCA = 8100 (pág. 10).

El impacto climático real depende tanto del PCA como de la masa emitida: `Impacto Global = PCA × Cantidad emitida` (pág. 10).

## Valores de referencia

- Valor patrón de referencia de PAO: R11 / R12 = 1,0 (págs. 1, 10).
- Valor patrón de referencia de PCA: CO2 = 1,0 (págs. 1, 10).
- PAO y PCA del R134a: PAO = 0 ; PCA = 1430 (pág. 10).
- PAO y PCA del R1234yf: PAO = 0 ; PCA = 4 (págs. 10, 26).
- PAO y PCA del R12: PAO = 1,0 ; PCA = 8100 (pág. 10).

## Errores de concepto frecuentes

- Juzgar el impacto ambiental total de un gas considerando únicamente su índice PCA, omitiendo la masa total de refrigerante fugada o emitida a la atmósfera (pág. 10).
